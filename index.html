moyai

moyai は、作者本人だけが使う個人用の予定・やること管理のツールです。一般には提供していません。

作者自身の Google アカウントの ToDo・カレンダー・Gmail を、作者自身のパソコンから読み書きするために Google の API を使います。

moyai is a personal productivity tool used only by its author. It is not offered to the public. It uses Google APIs to access the author's own Google Tasks, Calendar and Gmail from the author's own computer.
